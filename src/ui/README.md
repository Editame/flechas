# UI

Chrome de la app, compartido por todos los juegos:

- `arranque.tscn`: decide intro (primera vez) o hub.
- `intro.tscn`: historia de Editame y caja de sugerencias.
- `hub.tscn`: tarjetas de juegos desde `src/games/catalogo.json`.
- `ajustes.tscn`: preferencias, historia, legal y servidor (bandera).
- `tema_ui.tres`: tema base de Godot.
